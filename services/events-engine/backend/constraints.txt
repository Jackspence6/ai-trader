# Pinned dependency set for the Event Markets engine.
#
# pyproject.toml states what the engine needs; this states exactly which
# versions were tested. Without it, `pip install -e .` on the deployment box
# resolves the tree fresh and can install something the 137 engine tests never
# ran against — which is how a working system becomes a broken one between the
# machine it was built on and the machine it runs on.
#
# Used as a constraints file (`pip install -c constraints.txt -e '.[dev]'`) in
# scripts/setup-engine.mjs and in the engine's Dockerfile. Constraints only
# bound what is actually being installed, so the dev-only pins below are inert
# in the container.
#
# To regenerate after deliberately upgrading something:
#   .venv/bin/pip install -e '.[dev]' --upgrade
#   .venv/bin/pip freeze --exclude-editable | sort > constraints.txt
#   pnpm test:engine
#
# Resolved on Python 3.11. Everything here publishes wheels for both linux and
# macOS on arm64 and x86_64.
